# TACZ 枪械

[文档](README.md) · [English](../en/tacz.md)

将 `folkways-tacz-*.jar` 与 Core、Vanilla、**非官方 NeoForge 1.21.1 TACZ 移植版 1.1.8-hotfix-r7** 一同安装。
此扩展为可选模组；未安装时，殖民地仍使用普通近战、弓和弩。

在殖民书战斗页选中小队，再从服务器可用装备中选择枪型。
居民会到 32 格内的登记仓库领取对应枪械和口径的实物弹药。
手动交给居民的枪械也能用于推断补弹需求，弹匣和膛内弹计入备弹总量。
枪械属于可选装备，不会成为所有巡逻者的必备工具。
补给只计算可用的实物枪械；即使枪型相同，不可用的副本也不会占用可用枪械的背包保留名额。
旧殖民地保留原有工具许可；若尚未允许 TACZ 枪械物品，需要先在殖民地工具设置中放行，才能从仓库领取。

服务器在其服务端配置目录中生成 `folkways-tacz-server.toml`：

| 设置                  | 默认值                          | 作用                                                                |
| --------------------- | ------------------------------- | ------------------------------------------------------------------- |
| `allowedGuns`         | `[]`                            | 允许兼容的内置枪械；填写列表后限制枪型 ID，也可明确放行其他常规枪包 |
| `targetRounds`        | `32`                            | 散装弹药、弹匣和膛内弹的总目标                                      |
| `lowWaterRounds`      | `8`                             | 总数降到此值或以下时补给                                            |
| `rangeCap`            | `24`                            | 开火距离上限；守卫交战范围仍为 12 格                                |
| `gunRangeCaps`        | `tacz:m1911=16`、`tacz:m870=12` | 各枪型射程上限，受 `rangeCap` 限制                                  |
| `protectColonyAllies` | `true`                          | 保护同殖民地居民及宠物免受己方枪弹伤害，也覆盖已在飞行的子弹        |

友军居民、玩家和殖民地宠物挡住射界时，居民会停火。
殖民地流弹碰到方块即停止，不打碎玻璃或触发方块。
首版不支持爆炸、燃烧、燃料、虚拟／无限弹药、蓄力武器及未知枪械脚本。
常规内置换弹和拉栓脚本按名单放行；已安装配件和实际弹体效果也会检查，高爆或燃烧改装仍不可用。
脚本每次只能装入实际从背包扣除或从弹仓移出的弹药，卡顿补算不会增加弹药。
其他居民身体种类暂不适用。

玩家皮肤和使用常见手臂骨骼名称的 Geo／女仆模型可显示瞄准姿态，后者也会绘制手持物品。
首版不提供 TACZ 玩家专用换弹动画或特定模型包的动作片段。

专项服务端测试命令：

```sh
./gradlew --no-daemon -PtaczTests=true -PgameTestMod=tacz runGameTestServer
```

只加 `-PtaczTests=true` 会在加载 TACZ 的环境中运行整套测试。
Blockwright 使用 `blockwright.toml#tacz`，根配置已固定 jar 与 SHA-512。
拔枪、换弹、拉栓和点射按毫秒计时，测试不能仅依赖加速 tick 数。

真实客户端冒烟测试会另外加载车万女仆，分别验证皮肤、Geo 和女仆外观：

```sh
npm exec -- playwright test --config tests/e2e/playwright.config.ts tacz-combat.spec.ts --workers=1
```
