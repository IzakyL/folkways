# 玩法指南

殖民书打开后进入**概览**，显示需要处理的问题。**居民分工**用于管理居民，**库存与订单**显示物资和订单。
在**设施**中可按类型筛选并打开卡片。**设置**按**殖民地**、**产业**和**职业工具**组织殖民地设置卡片，其后是**个人偏好**和**高级**。
**教程**提供 Ponder 演示。

潜行并滚动滚轮，在殖民书工具栏选择类型。选择**纳入**后可登记单独的方块。圈地时左键标记两个对角，画路径时依次
左键标记各点。右键完成绘制并打开卡片。手持殖民书右键已纳入的区域、路径或方块，可再次打开其卡片并修改设置。

## 殖民地与成员

<!-- guide:colonies-and-members -->

殖民地属于玩家。创始人在**成员**页发出邀请，对方接受后才会加入；只有创始人可以结束殖民地。
点击面板标题可切换殖民地或创建新的殖民地。
任何一本殖民书都会打开你当前代表的殖民地，因此丢失书不会导致丢失殖民地。

安装 FTB Teams 后，创始人可将殖民地交给队伍。之后由队伍成员关系决定谁能管理殖民地，队长持有创始人的权限。

## 工作与容器

<!-- guide:work-and-storage -->

在**居民分工**页为每位居民排列工种优先级，殖民地负责安排任务、物资与执行顺序。
农田、牧场、蜂场、渔场和巡逻路线规定工作地点；库存订单规定容器应保有的物品与数量。

每个容器可分别允许或拒绝居民取走物品、将其用于普通存放。
即使拒绝普通存放，库存订单仍能向该容器交付。
黑名单和白名单共用物品选择器，支持物品、标签和搜索规则。
这些规则只约束居民，玩家和外部自动化保持原本的访问方式。

## 搜索

<!-- guide:searching -->

在客户端安装 [Just Enough Characters（JEC）](https://www.curseforge.com/minecraft/mc-mods/just-enough-characters)，
即可在物品选择器、目录选择器、居民分工和库存搜索中使用全拼、首字母及中文与拼音混合输入。
搜索沿用 JEC 的键盘方案和模糊音设置。JEC 是可选依赖，不随 Folkways 内嵌；未安装时仍可按文字搜索。

使用中文物品名称和 JEC 的全拼方案时，`tieding`、`td`、`tie锭` 都能找到**铁锭**。
物品搜索中的 `@minecraft tieding` 会将结果限定为 Minecraft 的物品。
其他键盘方案使用对应的拼写；搜索不区分大小写。

物品搜索保留 `@mod`、`#tag`、物品 ID 和通配符语法，这些条件匹配注册标识符。
按名称找到物品后，可以选中该物品来加入筛选器。
将搜索条件保存为筛选规则时，规则仍按 ID 和标签匹配，不使用翻译名称或拼音，
因此其含义不受玩家语言和 JEC 设置影响。

居民停止工作时，可在殖民书**设置**页的**高级**中开启**调试日志**。开启后注视居民或已纳入的方块可显示其调试卡片。
聊天栏每十秒显示当前规划耗时、空闲人数、任务数量、最近的阻塞原因，以及路线优化是否触发过兜底。
阻塞原因和任务样本来自最近完成的调度；规划繁忙时，它们可能早于实时居民状态。
日志只发给开启选项的玩家，关闭书后继续发送，退出服务器后自动关闭。

同一开关还会即时报告任务被抢占、工作或寻路失败、规划异常与优化兜底。
任务消息包含居民名称、任务、位置及目标；拾取消息还标明掉落物的名称和实体编号。
抢占消息会注明接管的个人行为、当时的战斗目标和最近伤害来源，这些现场信息尚不能直接认定为触发原因。
事件覆盖该殖民地的各维度。重复事件在五秒内合并，突发事件每两秒最多发送四条；
排队事件保留次数，超出队列容量时另发合并统计。关闭选项后，自己的待发消息也会清除。

路线优化设有计算量预算，普通规划模式下还设有 100 毫秒的时间上限。
达到任一上限后，调度器会还原并下发优化前的有效分配，让居民先执行工作，再在后续调度中改进路线。

## 牧场

<!-- guide:pastures -->

目标表示要保留的成年牲畜数量。总头数不足或刚好达标时，居民会成对喂食可繁殖的成年牲畜；
达标后允许继续繁殖一头余量，已有多出的幼崽时先等待它成年。只宰杀超过保留数量的成年牲畜，
幼崽不会提前顶替成年种畜。

例如保留两头牛：两头成年牛繁殖，幼崽长大后从三头成年牛中宰掉一头，正常繁殖冷却结束后继续循环。
设为 0 时不再繁殖，并清理所有成年牲畜。单头牲畜没有繁殖伴侣；持续产肉至少需要保留两头。

## 工种、等级与特长

<!-- guide:trades-levels-and-perks -->

居民会自动学习。每完成一秒有效工作获得 1 点经验；搬运和巡逻途中实际走动的时间也计入。
每个工种有十级，累计有效工作 3、8、15、25、40、55、75、100、130 和 160 分钟时依次升级。
居民的详情窗口会列出他的工种、等级和特长。

下表七个工种每升一级，从该工种五个互相独立的特长中抽取一级，每个特长各有三级。到五级时，居民至少已发现三种不同的特长。
3、6、10 级还会从通用特长池中抽取；通用特长在各工种之间共享。
满级的特长会退出抽取池；通用特长全部满级后，之后的通用里程碑不再给予奖励。
每个工种共有十五个特长等级，但只有十次抽取，所以每个居民会自然形成不同的组合。

| 工种 | 独立特长（I / II / III 级默认值）                                                                                                                                                                                                         |
| ---- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 建造 | 熟练施工：工作速度 +10% / 20% / 35%；寻矿：4% / 7% / 11% 概率找到矿物；时运：用工具破坏的方块获得时运 I / II / III；开山：连续采石速度最高 +15% / 30% / 50%；工具专家：工具磨损减少 15% / 30% / 45%                                       |
| 农业 | 熟练农夫：速度 +10% / 20% / 35%；连片收割：额外收割 1 / 2 / 4 株相邻成熟作物；丰收：食物产量 +10% / 20% / 35%；随收随种：自动补种，并有 0% / 15% / 30% 概率省下种子；精心照料：照料过的分龄作物生长 +10% / 20% / 35%                      |
| 放牧 | 熟练牧人：速度 +10% / 20% / 35%；物尽其用：普通屠宰掉落 +15% / 30% / 50%；丰毛：平均多剪 0.5 / 1 / 1.5 份羊毛；繁育能手：在牧场目标数内有 5% / 10% / 20% 概率生双胞胎；悉心饲养：每只幼崽限一次，喂食额外缩短剩余生长时间 10% / 20% / 30% |

| 搬运 | 重载：容量 +25% / 50% / 100%；健步如飞：搬运移动速度 +8% / 16% / 25%；快进快出：存取动作缩短 15% / 28% / 40%；顺路捎带：合并 2 / 3 / 4 份同起点或同终点的货物；长途脚力：步行疲劳减少 15% / 30% / 45%                                     |
| 制作 | 巧手：手工速度 +15% / 30% / 50%；批量作业：每次操作制作 2 / 3 / 4 次；节料：符合条件的配方有 5% / 10% / 15% 概率返还原料；副产物：10% / 20% / 30% 概率获得已配置的副产物；炉火经验：自己装入的那批原料烧炼速度 +10% / 20% / 30%             |
| 巡逻 | 威慑：守护半径 +2 / 4 / 6 格，持续时间 +15% / 30% / 50%；武艺：对敌对生物伤害 +10% / 20% / 35%；坚守：受敌对生物伤害减少 5% / 10% / 20%；警觉：侦测范围 +2 / 4 / 6 格并共享威胁；安民：守护带来的安全心情 +2 / 4 / 6，受袭后恢复更快      |

通用特长包括：触及距离 +0.5 / 1 / 1.5 格；移动速度 +5% / 10% / 15%；饥饿和疲劳消耗减少 10% / 20% / 30%；
食物、住房和天气带来的心情扣分减少 15% / 30% / 45%；聊天恢复的娱乐值提高 15% / 30% / 50%，双方都受益。
「专注」是只有一级的耐心特长。

部分特长另有细则：

- **寻矿**按开采位置实际所在生物群系的矿石地物挑选矿物，权重考虑生成次数、稀有度、矿脉大小、高度分布和可替换方块。
  找到的矿物按普通矿石战利品掉落，不受时运或精准采集影响；III 级另有 15% 概率多得一份。玩家放置的石头和反复开采同一位置都算数。
- **时运**作用于用工具破坏的方块掉落。工具自身的时运更高时以工具为准；工具本身不会被附魔，寻矿的发现也不受影响。
- **连片收割**不会越出农田，也不会抢占其他正在进行的作物任务。**精心照料**在作物一生中持续有效且不叠加，只支持分龄作物，不支持树苗。
- **顺路捎带**只重新排列已就绪、剩余路线仍装得下的工作。同终点取货最多多走约 8 格直线距离；有障碍时实际路程可能更长。
- **炉火经验**跨存档记录居民装入的批次；取走或替换这些原料，对应的加成也随之取消。

读档时恢复已保存的经验和等级，可识别的特长等级会被截断到上限。
数据包可以用 `crafting_perks/<配方路径>.json` 数据文件调整配方返还和副产物，用
`folkways_vanilla:gameplay/fishing_discoveries` 战利品表调整钓鱼发现。

## 战斗配装

同一聚落的居民、宠物、所属实体和成员玩家之间免疫伤害。自动射击会预测弹道和爆炸范围，避开聚落实体与方块。
玩家选定的攻击目标跳过瞄准预测，爆炸遵循原版或所装模组的规则。

<!-- guide:combat-equipment -->

在哨区或巡逻路线的卡片上，多选**允许的装备方案**并填写总**人数**。聚落从已分配这些配装且
未在其他地方服役的居民中自动补员；人数为零时停用。哨区仍要求远程配装和安全站位容量。
卡片显示到岗／目标人数及缺员原因，路线受阻可**重试路线**。有效现任成员保留，空缺优先补已纳入的武器站，再补哨区和路线。
居民从已登记的仓库领取分配的装备，可在居民卡片上查看。

在**设置** → **产业**的**巡逻**卡片上，可设置无配装居民的行为。默认会逃跑，也可允许他们使用已有装备迎战。
已分配居民按距离与弹药选择武器，近处或缺弹时改用近战。
RTS 战斗页显示已有配装。战斗装备独立于生产工具列表；副手尚未纳入既有护甲处理。

配装可要求携带望远镜作为补给。只有实际携带所需器材才有望远镜倍率（默认 2 倍）。视野逐观察者与目标计算：高处增加距离，
目标位置的低有效亮度缩短距离；夜视、着火或发光目标豁免黑暗惩罚，但始终需要无遮挡视线。
无警觉技能时，默认白天平地 32 格、八格眼高优势 44 格、该城墙携望远镜 88 格（平地为 64）。
有效亮度 0–4 时，无望远镜平地为 8 格。近距下限仍为 3，总上限仍为 128。
旧服务器配置保留原基准值，须显式改为 32 才采用新默认。哨位圆环只是上界，不保证圈内所有目标都能被发现。
普通哨区只用配装手持武器；火炮须逐台明确纳入，随后自动补员。
请保留通往实际炮体外安全站位的步行通路。居民会选择炮体外侧紧邻一圈的可达候选，
到达即登炮，无须等待敌人或再检查交互距离；迫击炮仍在炮旁操作。通路受阻时保留操作员名额，清障后可重新尝试。

## 随身口粮与食物名单

<!-- guide:rations-and-food-lists -->

居民默认随身携带三天的食物，剩余不足一个工作日时补充。每天的口粮按营养值计算而不是按个数，所以不同食物所需数量不同。

**设置** → **产业**中的**饮食与日常需求**卡片提供**食物名单模式**，可切换白名单和黑名单，**随身口粮**使用物品选择器，支持物品、标签和 query 搜索规则。切换模式保留当前规则：白名单只允许匹配规则的食物，黑名单拒绝匹配规则的食物。空白名单不允许任何食物；空黑名单允许所有安全且有营养的食物。名单同时约束居民从背包进食、口粮配送、背包预留和新居民的食物要求。用餐区的餐桌饭改按该区域自己的**餐桌食物**选择。没有可用食物时，食物要求仍显示为未满足。

默认使用白名单，规则为 `#folkways_vanilla:resident_food`。它组合以下标签：

- `#folkways_vanilla:resident_food_vanilla`：原有的 15 种熟肉、熟鱼、面包、汤等原版口粮。
- `#folkways_vanilla:resident_food_cookery`：森罗厨房的米饭、面食、熟肉和日常成品料理。
- `#folkways_vanilla:resident_food_farmers_delight`：农夫乐事的熟肉、三明治、汤、米饭、意面和分装大餐。

模组物品使用可选条目，未安装对应模组不会影响加载。默认不将生食原料、危险料理、特殊用途食品或需要先放置的大餐方块作为口粮。整合包可通过数据包扩展或替换这些标签；玩家也可在选择器中增加其他模组的物品、标签或 query。已有殖民地保留保存的食物规则，并默认按白名单解释；如需采用新的默认名单，可将规则改为 `#folkways_vanilla:resident_food`。

食物名单模式旁的“始终拒绝不安全的食物”复选框默认勾选。勾选时，加入白名单也不会允许危险食物。居民会跳过任何有概率附带负面状态效果的食物，也会检查迷之炖菜保存的效果。背包里已经携带的危险或被名单禁止的食物同样不会被吃掉，后面格子里的允许食物仍可正常食用。有益食物效果及碗、瓶等容器的返还保持正常。

取消勾选后，危险食物也可用于进食和口粮规划，但仍受黑白名单约束。

启用安全检查时，计算补粮需求不会将背包内的危险食物计入可用营养；被名单禁止的食物始终不计入。森罗厨房的红辣椒和青辣椒会在食用时直接造成伤害，因此居民也会拒绝食用。数据包可通过 `folkways_vanilla:unsafe_food` 物品标签补充其他具有特殊伤害行为的食物。

## 用餐区

<!-- guide:dining-areas -->

在殖民书工具栏选择**用餐区**，把餐桌和旁边的椅子都圈进去，再在卡片上选择**餐桌食物**和**每格桌面份数**（1 至 4）。
餐桌须来自受支持的模组（如森罗厨房），或属于 `#folkways_vanilla:dining/tables`、`#folkways_vanilla:housing/table` 方块标签；下半楼梯可作椅子；没有受支持的餐桌时，用餐区不可选。每把椅子旁要留出过道。同一高度相连的桌面算一张桌子，居民可从任意可达的边缘上菜。

居民每次从殖民地库存送来一份，让桌上始终摆着食物。选了多种餐桌食物时，每个空位会随机点一道菜单上的菜，并保持这个选择直到送达；
这些需求可以直接驱动生产。无物品栏的受支持餐桌只能摆一份可放置的食物，例如蛋糕；受支持的森罗厨房餐桌可摆放可食用的食物，并按份数设置摆放。
居民会保留食物组件，不动玩家亲手摆的食物；移除用餐区时，会把没用完的物资送回。

饥饿的居民优先去附近有空位的餐桌，吃完后归还食物容器。小份食物必须装得下他剩余的胃口；
营养值至少为 10 的大餐最多可超出有效营养的 30%（上限 6 点），所以不必饿到极点才吃大菜。
吃完一顿餐桌饭会获得一天的 +6 用餐心情。没有合适的餐桌饭时，居民吃随身口粮。中途取消用餐不会动桌上的食物，座位也会空出来。

## 住房与心情

<!-- guide:housing-and-mood -->

用书纳入殖民地的床会自动检查所在房间。门即使开着也会分隔房间，门两侧都要能走到。
所有评级房间都需要四面围合、有屋顶、有入口，可用空间的亮度至少为 8。手持书可看到每张床上方的卡片：谁睡在这里、房间等级和下一步改善建议。

| 住房     | 每床地面   | 每间床数  | 陈设类别                           | 心情 |
| -------- | ---------- | --------- | ---------------------------------- | ---- |
| 简陋床位 | 不满足要求 | 不限      | 不限                               | −6   |
| 合格宿舍 | 4 格以上   | 不限      | 不限                               | +2   |
| 舒适住房 | 6 格以上   | 最多 4 张 | 2 类以上                           | +6   |
| 优质卧室 | 9 格以上   | 最多 2 张 | 3 类以上，且没有生产方块           | +10  |

陈设类别为储物、织物、装饰、桌子和照明；同一类放得再多也只算一类。工作台、熔炉等属于生产设备，不算陈设。
没有床的居民心情 −12。房间检查最多覆盖 1,024 格地面、距床 32 格以内、上方 12 格以内的屋顶；未加载或过大的房间会保持待检查。
附近方块变化会刷新检查结果，定期复查也能发现命令或机器造成的改动。房间内或贴在房间墙上的空白告示牌会自动显示住户姓名。
玩家编辑过的内容会保留；最后一位住户离开时，自动写上的名牌会被清空。

人类居民有 0 到 100 的心情。食物、住房、休息、娱乐、陪伴、安全和周边环境决定心情的目标值，心情会逐渐向它靠拢。
工作速度在心情 0 时为 75%，60 时为 100%，100 时为 115%。居民详情窗口列出每一项来源；头顶卡片在饱食和精神旁显示心情概况。

## 娱乐与来访动物

<!-- guide:recreation-and-visiting-animals -->

空闲的居民会散步、四处张望、两两聊天、在花丛边歇一会儿，或抚摸殖民地成员驯服的猫和狼。
活动进行时就会恢复娱乐值，重复同一种活动收益递减。工作会打断普通娱乐，但娱乐长期不足的居民可能在两份工作之间短暂休息。
抚摸宠物不会改变主人设定的坐下状态，也不会接管宠物的寻路。

殖民地发展起来后，猫、狼和鹦鹉可能在附近安家。每个维度中，有合格床位的人类居民达到三人解锁猫，六人解锁狼，十人解锁鹦鹉。
所有维度合计，每三名住进合格房间的居民可容纳一只来访动物。每半个 Minecraft 日有 50% 概率在合适住房附近尝试一次，前提是居民已加载且开启了生物生成。
落脚点需要已加载、有光照、干燥、无遮挡，并远离敌对生物。来访动物未经驯服，可以照常收养，并像命名过的动物一样不会消失。
重新加载或卸载区块不会多刷出动物。动物死亡或移走后会空出名额；人口减少时暂停新的来访，但不会移走已有动物。

## 堆肥

<!-- guide:composting -->

在殖民书工具栏选择**纳入**来登记原版堆肥桶。殖民地默认保留 **64** 份种子，再将多余的种子用于堆肥。

居民只会将多余的种子用于堆肥；播种、已预留的输入和库存订单仍受保护。
Core 与 Vanilla 即可使用原版堆肥桶，不需要 Cookery 或草帽。
安装森罗厨房后，其种植材料也纳入同一套保留机制。

创造补给箱同样属于 Vanilla，不依赖 Cookery。

## 养蜂

<!-- guide:beekeeping -->

在工具栏选择蜂场类型，圈入蜂巢或蜂箱，在卡片上选择产出**蜂蜜瓶**或**蜜脾**。
蜂场采收沿用放牧工种：蜂蜜瓶需要玻璃瓶，蜜脾需要剪刀，居民只采收已经成熟的蜂箱。
蜜蜂仍按原版机制采花、产蜜，因此需要准备蜂群与附近的花源。

对于没有有效营火烟气的蜂箱，蜂场会在其下方地面提出营火建造需求，
由建筑居民使用殖民地物资完成。烟气有效后才会安排采收，蜂场会显示缺少烟气的蜂箱数量。
如果下方没有合适的地面空间，或烟气路径被阻挡，需要调整布局；已有营火熄灭时，需要手动重新点燃。

## 建筑

<!-- guide:buildings -->

圈出地块或画线后选择样式，居民会清理现场，使用殖民地库存建造道路、拱桥、城墙、码头、矿场、铁路、拱廊和梯田。
整栋建筑可在**蓝图**页放置。安装机械动力后，也可以把机械动力蓝图交给殖民地施工。

助手可以读取你提问时在殖民地手册中留下的标记。等待确认的建造方案会显示预览方块。确认后，订单才会提交给殖民地。

自己的样式、结构件和蓝图放入 `<game>/folkways/` 资料库文件夹或数据包，然后执行 `/reload`。

## 采集野生食物
<!-- guide:groundwork-gathering-wild-food -->

在整地区域开启**采集**，并关闭**清理**和**填充**，农夫就会拆掉圈定的食物植物，把正常掉落的物品运入殖民地容器。
采集默认关闭。

采集是清地，不是收获：甜浆果灌木、洞穴藤蔓和其他野生植物会被拆掉，不会补种。未成熟的植物也会拆，
只按当前阶段掉落，幼小的浆果灌木可能什么都不掉。开启**清理**或**填充**时，区域改为提交一份建造订单，完全不采集。
其他已开启的工作照常进行，例如砍掉支撑植物的树。

殖民地已登记的方块受保护。玩家种下但未登记的植物与野生植物无法区分，可能被采走。
一列洞穴藤蔓作为一项工作整列拆除，其中任何一段受保护时整列保留。两格高的植物从下半株整株采集。

包含：小型红蘑菇和棕蘑菇、南瓜、西瓜，以及农夫乐事的野生卷心菜、洋葱、番茄、胡萝卜、马铃薯、甜菜根和稻米，
森罗厨房的茶树、番茄和辣椒，Pam's HarvestCraft 2 Crops 的六种菜园，Supplementaries 的野生亚麻。
不包含：雕刻过的南瓜、巨型蘑菇、普通农田作物和树叶。Croptopia 的植物默认不包含。
数据包可以把植物加入 `#folkways_vanilla:forage` 方块标签。

整地只执行一次，完成的目标不会重做。重新圈定区域或修改设置后，才会发现新目标。

## 倒木
<!-- guide:groundwork-fallen-logs -->

整地区域的**砍树**也会清理倒木：横放在坚实地面上、没有连着竖直原木或树叶的原木。
原木上方或侧面的苔藓地毯、藤蔓、蘑菇和蕨会随原木一起收集，即使略微超出圈定范围。Quark 的空心原木也算倒木。

相连超过 64 格原木，或旁边有未加载区域时不处理。碰到站立树木的倒木留给普通砍树流程。
殖民地已登记的方块及其下方的方块受保护。玩家铺在地上、未登记的原木可能被当作倒木清走；悬空木梁和竖直木柱不算倒木。

**清理**会拆除圈定的每个方块，不收集这些装饰；想保留装饰请用**砍树**。数据包可以把类原木方块加入
`#folkways_vanilla:fallen_logs`，把附着的小植物加入 `#folkways_vanilla:fallen_log_decorations`。
区域圈定后才出现的倒木，需要重新圈定才能发现。

## 俯瞰视角

<!-- guide:overhead-modes -->

手持殖民书按 **V** 进入俯瞰视角。在工具栏选择要绘制的类型，或选择 **RTS** 指挥居民。
离开 RTS 后，服务器仍会保留已接受的编队和命令。

### RTS 命令

左键点选或拖动框选居民，Shift 添加或切换单人选择。左键点载具或玩家定义的设施则改为选中它。
普通右键是智能命令：点自己的载具时选中的居民登乘，点非友好生物或载具时攻击，点地面时移动过去。
Ctrl＋右键追加路径点，Ctrl＋右键较早的标记可闭合巡逻环线。同一路线的路径点共用移动模式；不按 Ctrl 右键地面可开始新路线。

九个编队按钮位于左下角。Ctrl＋1～9 或 Ctrl＋点击把当前选择绑定到编队（相同集合再次绑定会清除），1～9 或点击选回。
未选单位、正在同步、地面无效、路线超限等操作失败会以红字显示约三秒。

选择的命令卡位于右下角。**移动**（M）和**攻击**（G）先进入待命状态：随后左键点地面移动，或点目标攻击、点地面攻击移动。
按住 Shift 可连续下达同一命令；右键或 Esc 取消。右键点击移动或攻击按钮，可设为普通右键地面时的默认行为；离开 RTS 后恢复为移动。
**停止**（H）停下并原地待命。载具命令卡视情况增加**登乘**（B）、**离乘**（N）、**降落**（L）、**盘旋**（O）、
**诱饵弹**（C）、**加速**（X）和**详情**（I）。设施命令卡的按钮依次使用 R、T、Y、U、F、K，边缘滚屏相机下为
Q、W、E、R、A、S、D、F。J 解除对所选居民、载具和设施的 RTS 控制。可在“控制 → Folkways RTS”重新绑定按键。

设施卡片如果设有目标命令，按下该命令并在世界中点选位置，即可在该处执行。
如果该命令是卡片的默认命令，可直接右键点击该位置。

## 损害管制

<!-- guide:damage-control -->

在殖民书工具栏选择**损害管制**。左键标记两个角点，再右键保存并打开卡片。手持殖民书右键已有保护区域可再次打开卡片。

卡片提供**扑灭火焰**、**补回缺失方块**和**领用消防工具并补液**三个开关。修复默认关闭。整个区域加载后先点**重置基准**，再开启修复；首次记录也使用这个按钮。每个损管区域都会受到监护，旧存档中停用区域的设置会被忽略。使用卡片上的**移除**按钮删除区域。需要更改范围时，移除原区域并重新圈定，为新区域重置基准。俯瞰动作栏只保留保存框选区域和丢弃草稿。

保护区域有绿色轮廓。橙色标记火点，黄色标记缺失方块，紫色标记冲突，蓝色标记执行居民。悬停标记可查看详情，区域卡片显示事件数量并提供设置。

为需要响应的居民保持**损害管制**工种开启。开启灭火的区域内，火点直接成为损害管制工种的普通工作；该工种默认开启，普通工作优先级为
3，修复和补液也使用这一工种优先级，已保存的玩家设置仍优先。个人需求、遇险逃离和直接控制仍按正常规则优先。重叠区域共享火点和响应者。营火、装饰性火源和工业火源不会被扑灭。

基准只记录原版普通建筑方块，不记录容器、作物、流体、机器和 `#folkways_vanilla:damage_control_excluded` 中的方块。目标经施工打印器确认一次，连同方块状态表、相对坐标、修订号和 Minecraft DataVersion 保存。已有殖民地不会自动生成基准。无法识别的方块会跳过并报出；跨多个结构的区域不能记录同一份基准。

居民只补回缺失的方块，沿用建造的材料需求和放置路径。已有其他方块的位置会报出冲突并保留；门的开合变化不会触发修复。整扇缺失的门成组放置；只缺一部分的结构等待处理，不重置留下的部分。现有施工仍拥有其占用位置，火情响应优先于修复。改建后重新记录基准。基准不会恢复容器物品或居民。

为火场保留可行走的入口与安全站位。
喷射站位会提前为普通到达容差预留射程，并检查整个可能的视线通道；居民按普通规则到达后，直接尝试附加组件的原生喷射。
保守规划可能拒绝某些精确瞄准原本能喷到的贴墙站位。
每个任务固定所选工具和站位，包括水带的领取柜与喷位。
真实付费喷射后等待五个服务端刻；目标火块若仍燃烧，则直接徒手移除并完成。
未到达站位、缺水或柜子被占用的失败均不会触发兜底。
不可达路线会失败并稍后重试。
保护区域本身不会禁止居民进入。

原版居民近身徒手扑灭普通火焰和灵魂火，不会放置水源。装有 **机械动力：消防附加**（Create: FireFighting Additions）后，居民优先连接附近备好水带、锥形或扁平喷头和水的消防栓柜。柜子由一名居民或玩家独占，居民与柜子的连接最多为 32 格；喷射距离使用附加组件的有效设置（通常锥形 50 格、扁平 35 格，并受其速度与阻力的物理上限钳制）。取水后，当前位置安全就直接喷；否则选择离栓近、尽量远离火场的可达站位，不必靠近已经在射程内的远处火点。当前锁定版本在服务端沿直线采样灭火，显示的水滴则沿弧线飞行；站位规划遵循服务端效果，靠近障碍的射线可能被保守拒绝。每刻喷射从柜内消耗最多 10 mB，不足 10 mB 时可用尽余量。玩家接管、移除装备或柜子、工作中断、死亡和卸载都会立即释放连接并停止声音。喷射结束后，水带画面保留四个客户端刻，已喷出的水流继续飞行到结束，不再消耗水。居民的水滴和水带沿用附加组件的显示方式。

没有可用消防栓柜时，居民从殖民地仓库领用灭火器，通过附加组件的喷射耗液接口使用水：每次两刻的喷射消耗 5 mB，最远四格，并检查遮挡。目标火点来自看护区域；附加组件的原生锥体采样也会扑灭无阻挡路径上的附近火焰。附近跟踪居民的客户端会沿服务器给出的目标方向显示原生锥形水雾或水带水滴。自动灭火通常一次付费脉冲就完成，短雾明显弱于玩家持续按住使用键的喷射；持续付费脉冲会持续产生喷流，停止后只保留已喷出粒子的自然尾迹。附加组件的粒子密度和客户端粒子设置仍然生效。目前仅支持水。

补液使用殖民地补给处的流体接口，包括水桶。
居民也可用殖民地仓库中的空桶，在开启补液的区域内取水；取水会消耗水源方块，装入灭火器后归还空桶。
补给发现与区域扫描共享预算。
只有整桶水都能装入时才会清空水桶，流体储罐可少量补充。
空灭火器补液前回退为徒手扑火。
居民停做损害管制、死亡、卸载或殖民地关闭时，工具恢复为普通货物，可归还仓库。
自动消防只使用水；移动结构上的消防尚未经过客户端验证。

服务器 `damageControl` 设置默认将区域限制为 32,768 格，每个殖民地每刻共享 512 格扫描预算，同时最多四名居民响应。居民共用扫描记录和每刻选点额度，选点总次数与响应人数上限相同；每次从轮换的一批至多 128
个火点中寻找站位，暂时无法接近的目标间隔一秒再试。扫描额度在维度间轮换，即使每刻仅一格也不会漏掉某个维度。每次火情调查最多保留 4,096 个待处理火点。消防栓柜在自身更新时加入清单，每次查找至多检查 64
个柜子，并轮换后续条目，不遍历其他方块实体。修复检查同样轮换，关闭某个区域的修复后，仍启用的重叠区域可接手。施工打印器还将基准的最长边限制在 1,024 格。

## 控制中枢

安装机械动力后，手持**不记名打字机**右击频率为空的无线红石信号终端接收器。放下打字机，
即可绑定转换后的**控制终端**。在有标记的一面紧贴放置机械动力坐垫，设施运行时会召集居民操作终端。

## 电梯

<!-- guide:elevators -->

安装机械动力后，居民可以乘坐机械动力的电梯。照常建好并驱动电梯：电梯滑轮下方是粘合的轿厢，轿厢上有移动的红石触点，
各楼层有对应的电梯触点，轿厢旁有能走到的候梯平台。书处于点选手势时，左键电梯滑轮，把它纳入殖民地。
之后居民会规划跨楼层路线，在平台上等候，走进空闲的站位，到站后再走出来。

载客量取决于无遮挡、相连的底层地板，并会留出通行空间；多放座椅不会增加载客量。轿厢满员时，后来的居民会等下一趟。驱动停止或应力过载时无法乘梯。

## 森罗酒馆

<!-- guide:kaleidoscope-tavern -->

同时安装 Kaleidoscope Tavern（森罗酒馆）和 Kaleidoscope Cookery（森罗厨房）后，居民会种葡萄、酿葡萄酒，并在用餐区供应。

- **葡萄园。** 把农田作物选为葡萄藤，供应四株葡萄藤苗和棚架：每根立柱四个，每格田一个。
  居民会逐个摆放棚架，在四角立柱，再在整块田上方五格高处铺满藤棚；立柱完成后在柱脚种藤，收获棚下挂着的葡萄，藤留着继续生长。
  砍树时也会收走附着的野生葡萄藤。
- **酿酒。** 把榨汁盆和带龙头的酿酒桶登记为厨房工作站，再下葡萄酒订单。居民在榨汁盆里踩葡萄，从顶部把葡萄汁倒进酒桶，
  等到第二酿造阶段后逐瓶摆好、灌装、收走。取消的灌装任务会从龙头下留着的那个瓶子继续。
- **吧台饮品。** 在用餐区选择**吧台饮品**，在区内放置吧台和相邻的椅子。每个吧台存放两瓶酒，品质等数据在存档中保留。
  用餐区的吧台专供饮品服务。居民会从殖民地仓库或生产中补充空槽，与饥饿无关地去坐下喝一杯；食客吃完餐桌饭后也可能去取一瓶。餐桌只摆食物。
  喝酒会带来这种酒本身的效果，归还空瓶，并获得一天的 +4 心情，但不提供营养。拆掉吧台会返还其中的酒。

## 女仆模型包

<!-- guide:maid-model-packs -->

车万女仆的内置及已安装扩展包模型可以成为居民外观，可逐个或按包选择。
这些模型外观需要 GeckoLib；缺少依赖时，相关选项会禁用并显示提示。

将 ZIP 文件或模型包文件夹直接放入服务器及每个客户端的 `<gamedir>/tlm_custom_pack/`。
ZIP 无需解压。每个客户端读取自己安装的模型包，服务器不会传输模型包素材。

调整模型包后，在服务器执行 `/reload`，并在客户端按 F3+T 重载资源，或重启游戏。
`config/touhou_little_maid/file/` 是下载缓存，不算已安装的模型包。
